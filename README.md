# Buddy — an interactive learning game for Lower KG

A touch-first web app for a child aged 4–5: look after Buddy the baby elephant through his day (habits, manners, feelings) and play with him on a map of mini-games covering the *My First Steps with Cambridge* Lower KG syllabus.
